Picking and layout

How does an operator find the right reel?

In the catalog’s light-guided workflow, the operator scans the reel barcode and the storage position when putting a reel away. When that reel is requested, the position lights up so the operator can pick it.

Should we specify single- or double-sided access?

Choose single-sided access if the trolley will be parked against a wall. If operators work on both sides of an aisle, request the double-sided layout and confirm the slot allocation for your reel mix when ordering.

We have only one metre of space. Which model should we look at?

The SIR5000C frame is 1,350 mm long. The SIR4000B compact mobile reel rack has a 1,000 mm frame and lists 300 positions for 7-inch reels and 23 for 13-inch reels. Allow additional clearance for handling with either model.
