Questions before RFQ

What should be confirmed?

A short checklist helps match the modular machine configuration to your board and line.

Which configurations are available?

The supplied PDF shows SC-912, SC-924 and SC-936 as one-set, two-set and three-set cutter configurations.

What board range is listed?

Board thickness is listed as 0.5-3 mm, board width as 50-300 mm and board length from 50 mm to unlimited.

Can it connect to an existing line?

The document lists SMEMA interface support and upper/lower trigger connection. Confirm the exact upstream and downstream equipment before order.

Is the speed adjustable?

Yes. The supplied specification lists a variable-speed motor with board speed of 300-500 mm/s.

What should I send for a machine review?

Send board thickness, width, longest board length, V-cut depth, panel format, target speed and line interface information.

Can you test my PCB?

Include a board sample or clear drawings with the RFQ so the cutter configuration and feeding setup can be reviewed.

Prepare the next step

Send your board size and line target for a configuration recommendation.

Include the PCB material, thickness, width, length, V-cut drawing, required speed and whether SMEMA or trigger signals are needed.
