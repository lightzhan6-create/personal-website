Operating sequence

Return a reel with a verified quantity

A partly used reel can return to stores with the quantity from its original label. Recount it at the cabinet before the next work order uses that number.

Load and identify

Place the reels on the counting tray. The label camera reads the barcodes so the count can be associated with each reel.

Count through the tape

The X-ray image reveals components in the pockets. The software determines the quantity without unwinding the reel.

Relabel and return

Review the count, print the new quantity label and apply it to the reel. For a connected inventory system, agree on reel IDs and data fields during integration.

Application review

Before you specify

Does the 6–10 second figure apply to any reel?

It is the manufacturer’s counting example for four reels loaded with 0201 chips. Actual throughput depends on the reel mix, loading and the relabeling workflow.

How should we evaluate the counting result?

Send representative reels, including your smallest package and difficult-to-count parts. Compare the reported quantity with a known sample count and check the output label and system record.
