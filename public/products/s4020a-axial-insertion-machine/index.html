Product overview

A controlled route from component feed to PCB insertion

The supplied configuration describes single-process sequencing and insertion of axial components and jumper wires. It is intended for through-hole PCB assembly where component format, lead span, board size and feeder arrangement need to be considered together.

Axial tape-packaged capacitors, transistors, diodes, resistors and fuses are listed in the supplied material. The final configuration should be evaluated against the actual component, packaging method and PCB design.

  1. 01 / FeedAxial tape-packaged components and jumper wires are supplied to the insertion process.
  2. 02 / InsertThe platform supports programmed PCB insertion positions and specified theta orientations.
  3. 03 / ClinchLead clinch length and clinch degree are listed as adjustable in the supplied configuration.

Key features

Functions defined around axial insertion work

These points are taken from the supplied configuration and presentation material. Project-specific suitability remains subject to technical review.

01

Axial component insertion

Configured for axial tape-packaged components such as capacitors, transistors, diodes, resistors and fuses.

02

Full servo drive system

The supplied material identifies a Fuji full-servo drive system, including a 750 W head-drive motor and 400 W X-Y table motor.

03

Camera visual operation

A camera visual operating system is described for program preparation, including a stated five-minute new-PCB insertion-program setup.

04

Jumper-wire feed assembly

The supplied configuration includes a built-in jumper-wire feeding assembly for jumper-wire insertion work.

05

Feeder flexibility

UIC feeder compatibility is stated, with 60 stations recommended and an optional range from 10 to 100 stations.

06

Programmable clinching

Multiple clinch options are listed with programmable height, adjustable clinch length and an adjustable clinch degree.

Production flow

A practical insertion sequence for THT assembly

STAGE 01

Prepare components and PCB data

Review the axial component package, lead span, PCB size, board thickness and required feeder quantity before confirming the configuration.

STAGE 02

Program and position the board

The supplied material describes visual program preparation, programmed coordinates and insertion orientations of 0, 90, 180 or 270 degrees.

STAGE 03

Insert and clinch

Components or jumper wires enter the PCB insertion process; lead clinching is then set to the required supplied adjustment range.

Evaluation FAQ

Information that helps confirm a configuration

A clear project review starts with the component, board and production details rather than the model name alone.

What should I send for an initial evaluation?

Please send component photos, key dimensions, tape packaging details, lead span, a PCB file or board photo, and the expected production requirement.

Can the feeder quantity be discussed before purchase?

Yes. The supplied configuration lists 60 stations as recommended, with 10-100 stations optional. The appropriate quantity depends on the component set and the project.

Can jumper wires be included in the process?

The supplied material identifies a built-in jumper-wire feeding assembly. Please share the jumper-wire diameter, span and board information for technical confirmation.

Which values need final confirmation?

Component compatibility, feeder arrangement, actual production output and every final machine option should be confirmed against your component package and PCB data.
